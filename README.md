# java-racingcar-precourse

# 목표
- TDD(Test-Driven Development) 를 통해 기능 단위로 테스트 작성 및 검증
- 클래스의 단위 세분화 와 명확한 책임 분리(SRP) 를 실천

## 🔥 기능
- [x] 입력 기능
  - 사용자 이름과 반복할 횟수 입력 받아 게임에 전달하기

- [x] 문자열 구분 및 자동차 객체 생성
  - 문자열에 다음과 같은 규칙으로 자동차 이름 추출하기:
      - 입력 문자열을 , 기준으로 split
      - 이름 양쪽 공백 trim
  - 만들어진 이름만큼 자동차 객체 생성하기

- [ ] 게임 기능
  - 게임을 입력받은 횟수만큼 반복
  - 각 라운드마다 각 자동차는 0~9의 랜덤 값을 생성
    - 랜덤 값이 4 이상일 경우 자동차는 전진
  - 각 턴마다 모든 자동차의 진행 상태 출력
  - 게임 종료 후 최종 우승자(또는 공동 우승자) 계산

- [ ] 출력 기능
  - 각 라운드 결과를 콘솔에 출력 (- 표시로 진행 거리 시각화)
  - 게임 종료 후 최종 우승자/공동 우승자 출력

## 🧪 테스트 사항
입력 기능 테스트
- 입력 문자열에 , 구분자가 존재하는가

문자열 구분 및 객체 생성 기능
- 문자열이 정상적으로 split 및 trim 되는가
- 예외 입력을 적절히 처리하는가
```
공백, 5자리 이상, 문자포함 공백
ex) "poni,,woni", "longNmae,woni", "ab-de,pobi,woni"
```

게임 기능
- 랜덤 값이 4 이상이면 전진, 미만이면 정지하는가
- 게임이 반복될 때 각 턴의 진행상황이 누적되어 출력되는가

출력 기능
- 단독 우승자를 올바르게 출력하는가
- 공동 우승자를 올바르게 출력하는가
